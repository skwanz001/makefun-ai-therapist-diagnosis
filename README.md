The funniest single-line diagnosis an AI therapist hands its human, 200 characters or less. One deadpan clinical finding about a very human habit, with the laugh landing on the last beat: the therapist itself breaks character at the end.

## Run it

```sh
python3 main.py
```

It writes the one-line diagnosis to `/output/entry.txt` (144 characters, standard library only).
